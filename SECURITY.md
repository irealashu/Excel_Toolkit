# Security Policy

## Reporting Security Issues
If you identify any security issue, please contact the maintainers. Because Excel Toolkit does not have a backend server or persistent cloud storage, security concerns primarily relate to client-side input validation, sanitization of untrusted HTML/XML tables, and safe handling of OpenXML ZIP archives.

## Guarantees
- No remote code execution.
- No VBA macro execution.
- Pure client-side parsing.
