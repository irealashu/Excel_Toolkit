# Privacy Model

## Core Tenet
Excel Toolkit does not collect, log, transmit, or monetize your data.

## Guarantees
1. **No External Transmission**: File contents, workbook structures, column values, and calculations never leave your computer's browser process.
2. **Ephemeral Memory Lifecycle**: Uploaded files and generated datasets are stored only in volatile memory during your tab session. Closing the tab or refreshing permanently wipes this memory.
3. **No Trackers or Advertising**: No Google Analytics, Mixpanel, Hotjar, tracking pixels, or third-party cookies.
4. **Offline Capability**: After the initial static assets load, the platform continues to function identically when your device is completely disconnected from the Internet.
